**Javascript**:
1. What is JS? 
		Javascript is a scripting language, similar to programming language. 
		Scripting language: line by line code execution
		used to create interactive webpage
2. Why we need to use JS in frontend?
		to make interactive webpages
		
3. key components of JS
		Scripting language
		Interpreted language - no need for a compiler
		it is an object based language
		single thread language- one task can be performed at a time 
		asynchronous function -> promises
		works well on both client and server sides
		event handling
		case sensitive

	Parts of JS :
	i. Basic JS : print statement, operators, variable, data types , conditionals, loop, array, function, object
		browser(client) -> .html
		server -> node js
	ii. Intermediate JS : DOM, Event handling, BOM
	iii. Advanced JS (Ecmascript 6): React JS/ Angular JS
			NOTE: ES1 - 1997 1st edition
			     ES6 - 2015 - major update - frameworks
			     last update - 2024
		
		uses .js extention
4. script.js
		how to link js file?
		i. internal : script tag , before closing the body tag
		ii. external:  we have to create .js file , with src="fileName,js" 
		iii. inline - DOM event handling
